# Moon Courier Crisis

Небольшой 3D-симулятор лунной доставки на Unity.

Игрок выбирает заказ и ровер, учитывает вес груза, заряд батареи, тип местности и риск маршрута. Цель — за 3 игровых дня заработать как можно больше кредитов и очков.

## Как запустить

1. Скачать репозиторий.
2. Открыть папку `Build`.
3. Запустить `Moon Courier Crisis.exe`.

Unity для запуска готовой сборки не требуется. `.exe` должен оставаться рядом с папкой `Moon Courier Crisis_Data` и остальными файлами сборки.

## Что сделано

- 3D-карта Луны с кратерами и разными типами поверхности.
- База и 3 ровера с разной батареей и грузоподъёмностью.
- Заказы с весом, наградой, срочностью и риском.
- Проверка батареи и допустимого веса до запуска.
- Разная скорость и расход энергии на разных участках карты.
- Объезд препятствий, случайные события, аварии, диагностика и ремонт.
- 3 игровых дня с новыми заявками в постоянных точках.
- Кредиты, очки и итоговый рейтинг.

## Логика веса, риска и доставки

Если заказ тяжелее грузоподъёмности выбранного ровера, рейс не запускается. Необходимый заряд рассчитывается с учётом маршрута, веса груза и типа поверхности.

Процент риска в карточке — базовая вероятность аварии. Например, `РИСК 28%` означает 28%. Событие «Радиопомехи» явно добавляет `+8 п.п.` к риску текущего рейса.

Во втором дне есть специальный стратегический сценарий: две заявки весят **60 кг** и **68 кг**, поэтому их может взять только ВЕКТОР с лимитом 70 кг. Первая требует **47%** батареи, вторая **60%**. Вместе это 107%, поэтому за один день можно выполнить только одну из них. Игрок выбирает между наградой и риском.

После доставки меняются статус заказа, батарея ровера, кредиты и очки. При аварии доставка не засчитывается, а ровер может потребовать диагностику и ремонт.

## Хранение данных

Состояние игры хранится в JSON через `JsonUtility` в `Application.persistentDataPath`.

Сохраняются роверы, их состояние и батарея, заказы, доставки, игровые события, кредиты, очки и текущий день.

## Использование AI

В процессе разработки использовался ChatGPT (OpenAI) для проработки игровой логики, генерации и рефакторинга отдельных фрагментов C#, поиска ошибок, проверки логики веса / батареи / риска / маршрутов и подготовки документации.

Результат проверялся вручную в Unity после существенных изменений. AI не используется во время работы готовой игры.
